Pinly iOS fallback shell

Native setup is incomplete.

This screen means the Capacitor shell synced successfully, but it does not yet know which live Pinly app origin to load.

What Pinly expects

Pinly's iOS app is the existing Next.js product wrapped in Capacitor. The real app should load from CAPACITOR_SERVER_URL, not from this page.

Finish Local Setup

  1. Copy .env.capacitor.example to .env.capacitor.
  2. Set CAPACITOR_SERVER_URL to your local, LAN, or deployed Pinly origin.
  3. Run npm run ios:doctor to validate native prerequisites.
  4. Run npm run ios:sync to re-sync the iOS shell.
  5. Open Xcode with npm run ios:open or npx cap open ios.

Optional Firebase Push

Native push delivery remains unavailable until you add ios/App/App/GoogleService-Info.plist locally and sync again.
